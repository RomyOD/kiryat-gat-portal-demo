# פורטל תקציב ותוכניות עבודה - עיריית קרית גת (הדגמה)

סביבת הדגמה בלבד. המבנה הארגוני נלקח מאתר העירייה; כל הסכומים והמשימות בדויים.

## רכיבים
- `public/` - האתר הבנוי (מוגש כמו שהוא ב-Vercel)
- `api/users.js` - שרת ניהול משתמשים (Vercel Function); המפתח הסודי נשמר רק כמשתנה סביבה
- `src/` - קוד המקור (React)
- `supabase/` - מבנה מסד הנתונים, הרשאות (RLS) ונתוני הדגמה
- `test/` - בדיקות הרשאות ובדיקות קצה לקצה מול סביבה מקומית

## משתני סביבה ב-Vercel
- `SUPABASE_URL` - כתובת הפרויקט ב-Supabase
- `SUPABASE_SECRET_KEY` - המפתח הסודי (secret / service_role)

## בנייה מחדש
`node build.mjs` (דורש esbuild, react, react-dom, jszip)

## איפוס נתוני ההדגמה
הרצה חוזרת של `supabase/02_seed.sql` ב-SQL Editor. המשתמשים וההרשאות נשמרים.
